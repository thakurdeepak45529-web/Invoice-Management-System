# Invoice Management System

## Project Overview
This project is an Excel-based Invoice Management System designed to create professional invoices and manage billing details efficiently.

## Features
- Professional Invoice Format
- Customer Details Management
- GST Calculation
- Automatic Total Amount Calculation
- Invoice Number and Date
- Clean and Organized Layout

## Tools Used
- Microsoft Excel

## Project Purpose
The purpose of this project is to simplify invoice creation, improve billing accuracy, and maintain organized invoice records.

## Author
Created as a practical Excel project for skill development and portfolio building.
